# ТИМ Кампус

Новая платформа живёт в [`platform/`](platform/README.md). Опубликованный клиент 4.0.1 ниже остаётся действующим сайтом и APK, пока релиз платформы не заменит его в магазине.

Независимый студенческий проект для РГАУ-МСХА имени К. А. Тимирязева. React 19, TypeScript, Vite и Android-оболочка Capacitor. Проект не заявляет официальное одобрение университета.

[Веб-приложение](https://p44978180-del.github.io/raspos/) · [Релизы Android](https://github.com/p44978180-del/raspos/releases) · [Проверка безопасности](docs/security-audit.md)

## Реализовано в 4.0

- Новые адаптивные экраны: главная, расписание, кампус, планировщик, сервисы; светлая и тёмная темы.
- Поиск группы, преподавателя и дисциплины, календарь и ссылки на первоисточник каждого занятия.
- Локальные задачи, заметки, личные переносы и отмены; экспорт календаря ICS, резервная копия JSON и объединение записей при восстановлении.
- Схема кампуса с фильтрами и метками по предоставленному плану. Это схема, а не подтверждённая навигация по этажам.
- Офлайн-запуск веб-приложения после первой загрузки. Каталог и максимум три открытых расписания сохраняются локально; новые группы требуют соединения.
- Подписываемая Android-сборка с системной передачей файлов экспорта. Ключ подписи не хранится в Git.

## Данные и актуальность

Источники: [официальная страница расписания](https://www.timacad.ru/about/sveden/document/rezhim-zaniatii-obuchaiushchikhsia) и связанный с ней [электронный каталог](https://eg.timacad.ru/schedule/groups/).

Снимок от 21 сентября 2026 содержит 805 групп, 47 068 занятий на конкретные даты и 104 документа текущего семестра. В периоде 14 сентября–2 ноября у 463 групп есть занятия, у 342 электронный источник пуст. Пустой источник не означает отсутствие занятий: проверяйте документы института. Полная сверка электронного каталога с PDF всех форм обучения ещё не завершена. Демонстрационные группы и архивные PDF исключены.

Сборщик получает официальные страницы по HTTPS, проверяет учебный период и структуру, сохраняет ограниченное окно дат и файлы по группам с контрольными суммами. Ошибка источника не заменяет данные выдуманным расписанием. GitHub Actions настроен проверять источники каждые четыре часа; время запуска зависит от очереди GitHub. Дату последней успешной проверки показывает приложение. Последняя полная проверка успешно завершена 21 сентября 2026 без ошибок загрузки.

Весь набор расписаний находится на сервере. В APK входят оболочка, схема и каталог; расписания выбранных групп загружаются отдельно. Задачи и заметки сохраняются в IndexedDB и не отправляются серверу. Общая синхронизация личных данных между устройствами не реализована.

## Разработка

Требуются Node.js 22.18+ и pnpm 10.34.3.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm test
pnpm typecheck
pnpm build
pnpm sync:schedule
```

Для Android нужны полный JDK 21, Android SDK и параметры подписи ANDROID_KEYSTORE_PATH, ANDROID_KEY_ALIAS, ANDROID_KEYSTORE_PASSWORD, ANDROID_KEY_PASSWORD. Затем pnpm build:android. Локальный Windows-помощник scripts/build-local-android.ps1 использует отдельный ключ с ограниченными правами и пароль Windows DPAPI. Сохраните ключ и пароль вне репозитория: обновления должны иметь ту же подпись.

scripts/publish-release.mjs проверяет чистый Git, совпадение квитанции сборки с HEAD и удалённым main, цель тега и SHA-256 загруженных файлов. Он публикует APK, web ZIP, HTML-отчёт, квитанцию сборки и контрольные суммы. pnpm package:release только готовит архивы.

## Границы текущего выпуска

Это бета-версия. Установка и поведение APK на физическом Android-устройстве ещё не проверены. Браузерная сборка проверена на узком и широком экранах и повторным открытием после остановки сервера. Проверки данных, импорта копии, service worker и релиза автоматизированы.

Идеи общего режима старосты, подтверждений отмены, свободных аудиторий, Wallet/NFC, нативных виджетов и мини-приложений сохранены, но эти интеграции не подключены. Личные изменения не меняют официальное расписание и не отправляются группе. Для совместного режима нужны проверяемая идентичность и членство в группе. KMP, Rust, CRDT, 120 FPS и гарантированная задержка 0 мс не реализованы и не заявляются.

Прежние каталоги `backend/`, `kmp/` и `rust-core/` удалены. Рабочий сервер, ядро и телефонный клиент лежат в `platform/`.
