# 🌾 РГАУ Расписание — Мобильное приложение студента

Официальное кроссплатформенное приложение для студентов и преподавателей **РГАУ-МСХА имени К.А. Тимирязева**. Создано студенческой командой разработчиков и Студенческим советом университета.

Приложение объединяет расписание академических занятий, интерактивную карту кампуса на Лиственничной аллее, ленту университетских событий и анонсов, сервисы старостата и синхронизацию с официальными ресурсами академии.

---

## ✨ Ключевые возможности

- 📅 **Расписание занятий всех институтов** — 42 академические группы, 1 051 занятие, числитель/знаменатель (верхняя и нижняя недели).
- 🔄 **Автономная синхронизация в 04:00 МСК** — приложение на смартфоне автоматически сверяет данные с официальным порталом `timacad.ru` каждое утро в 4 часа и сохраняет данные для 100% офлайн-доступа.
- 🏛️ **18 официальных источников РГАУ-МСХА** — прямое подключение к новостям, анонсам, Профкому студентов, ЭИОС, Moodle, ЦНБ им. Железнова, спортивному клубу и дирекциям институтов.
- 🔔 **Умный трекер звонков** — статус текущей пары в реальном времени, обратный отсчёт до звонка, длительность перемен и большого обеденного перерыва.
- 👩‍🎓 **Кабинет старосты** — загрузка официальных PDF-расписаний, оперативный перенос/отмена занятий, закрепление важных заметок группы и домашние задания.
- 🗺️ **Интерактивная карта кампуса** — официальная картография учебных корпусов, общежитий студгородка, кафедр, буфетов и столовых с пешеходной навигацией.
- 📱 **PWA для iOS** — бесшовная установка на iPhone и iPad через кнопку «Поделиться» → «На экран «Домой»».
- 🤖 **Android приложение** — сборка нативного APK через Capacitor.
- 🌙 **Адаптивная тема** — светлый и тёмный режимы с плавной радиальной волной переключения.

## 🚀 Запуск и разработка

```bash
# Установка зависимостей
pnpm install

# Запуск dev-сервера
pnpm dev

# Проверка типов TypeScript
pnpm typecheck

# Запуск полного набора стресс-тестов
pnpm test

# Сборка веб-версии (PWA)
pnpm build

# Сборка Android-проекта через Capacitor
pnpm build:android
```

## 🏗️ Архитектура и стек технологий

- **React 19** + **TypeScript 5.7**
- **Vite 8** — высокопроизводительный бандлер
- **Tailwind CSS v4** — современная система стилей
- **Capacitor 8.5.1** — мобильный нативный контейнер
- **Service Worker / PWA Manifest** — офлайн-кэширование и запуск в режиме standalone на iOS/Android
