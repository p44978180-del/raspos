# ТИМ Кампус

Единственная точка входа для разработки платформы — [platform/](platform/README.md).

Независимый студенческий проект для РГАУ-МСХА имени К. А. Тимирязева. Проект не заявляет официальное одобрение университета.

## Компоненты

- [Мобильный клиент](platform/mobile/) — Kotlin, Compose Multiplatform и SQLDelight; Android и сборка iOS.
- [Сервер](platform/server/) — Go, Connect-RPC, PostgreSQL и OpenFGA.
- [Общее ядро](platform/rust/timacad-core/) — Rust и UniFFI.
- [Контракты](platform/proto/) — Protobuf.
- [Локальный контур](platform/deploy/) — Docker Compose, Caddy, Temporal, NATS и Centrifugo.

Инструкции по окружению, сборкам и запуску находятся в [руководстве платформы](platform/README.md). Каталоги `backend/`, `kmp/` и `rust-core/` удалены; они не используются для разработки или сборки.

## Статус Фазы 8

**Фаза 8 полностью закрыта 3 октября 2026 года.** [Релиз v8.0.0-platform](https://github.com/p44978180-del/raspos/releases/tag/v8.0.0-platform) закреплён за проверенным коммитом `9a3925fa1247ae3625f88722ec5378bddcb8c554`; подписанные APK/AAB и контрольные суммы опубликованы в релизе.

Подтверждены установка и нативный запуск на физическом ARM64, сетевой Bootstrap 805 групп / 47 068 занятий, доставка изменения в карточку и Glance, регистрация/вход по отпечатку через доверенный HTTPS и восстановление Android Keystore-сессии. Все 47 JVM-тестов и сборки iOS/WidgetKit прошли. Аудит вынес TMG1, Loro и сеть за первый кадр, FTS5 прогревается через две секунды. Измеренные 162–186 мс на TECNO приняты пользователем для этого профиля устройства.

[Релизный журнал](docs/phase8-release.md), [приёмка и исторические проверки](docs/phase8-acceptance.md), [аудит старта](docs/phase8-startup-audit.md) сохраняют точные замеры и согласованные исключения. Артефакты используют временный приёмочный HTTPS API/RP; настройка постоянного адреса описана в релизном журнале.

## Расписание

Исходный снимок v4 содержит 805 групп и 47 068 занятий в периоде 14 сентября–2 ноября 2026 года. У 342 групп электронный источник пуст; это не доказывает отсутствие занятий. Полный семестр и все PDF пока не подтверждены.

Источники: [официальная страница расписания](https://www.timacad.ru/about/sveden/document/rezhim-zaniatii-obuchaiushchikhsia) и [электронный каталог](https://eg.timacad.ru/schedule/groups/). Ошибка источника не должна заменять сохранённое расписание выдуманными данными.

Клиент v4 остаётся историческим выпуском. Его файлы используются для проверки паритета платформы.
