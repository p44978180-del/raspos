# ТИМ Кампус 4.0.0 — бета

Переработанный интерфейс, официальное расписание на конкретные даты, локальный планировщик и схема кампуса.

- 805 групп в каталоге; 45 816 занятий у 460 групп. У 345 групп электронный источник пуст — проверяйте PDF института. Снимок проверен 19 сентября 2026; обновление 20 сентября не удалось из-за тайм-аута официального сайта.
- Задачи, заметки, личные переносы и отмены, экспорт ICS, резервная копия JSON и восстановление.
- Каталог и до трёх открытых расписаний доступны офлайн. В APK не включён полный набор расписаний кампуса.
- Исправлены пять исходных находок частичного аудита Codex Security. Незавершённые общие изменения расписания отключены до внедрения авторизации.

## Загрузка

Скачайте tim-campus-4.0.0.apk из файлов релиза. Для установки Android может запросить разрешение установки из выбранного источника. Подпись выпуска отличается от старых отладочных сборок: при конфликте подписи сначала сохраните доступные личные записи, затем удалите старую сборку и установите новую. Совместимость импорта со старым форматом данных не заявляется.

SHA256SUMS.txt содержит контрольные суммы всех файлов. build-release.json связывает APK с commit и сертификатом подписи. tim-campus-4.0.0-web.zip предназначен для размещения на HTTP-сервере. release-report.html — автономный интерактивный отчёт.

## Проверки и ограничения

Пройдены 20 автоматических тестов, TypeScript, production build и целевые Go-тесты. Веб-приложение проверено на мобильной ширине и повторным открытием после отключения локального сервера. APK собран в release-режиме; подпись проверена. Установка APK на физическом устройстве не проверена.

Нет нативного iOS-приложения, Wallet/NFC, системных виджетов, подтверждённых маршрутов по этажам и общего режима старосты. Полная сверка всех PDF и полный аудит безопасности остаются работой следующих выпусков. Проект независимый и не является официальным приложением университета.
