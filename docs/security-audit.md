# Проверка безопасности ТИМ Кампус

Состояние: исправления внесены, проверка полного выпуска ещё не завершена.

Codex Security: скан `386b2691-8231-484d-859e-db6bc600a09a`, завершён 20 сентября 2026, покрытие **частичное**. Он зафиксировал исходное состояние во время переработки. Это не сертификат безопасности текущего APK. Независимый проверяющий завершил только часть обзора из-за ограничения доступного выполнения.

## Найденные проблемы и исправления

| Исходная проблема | Исправление | Проверка |
| --- | --- | --- |
| Клиент мог объявить себя старостой и подтвердить перенос | Публичные изменения, голоса и псевдо-RPC отключены до внедрения проверяемой идентичности | HTTP-тесты отправляют поддельную роль и проверяют 501 до обращения к БД |
| Анонимный запуск административного парсера | Маршруты закрыты токеном сервера; устаревший импорт отключён и для администратора | Тесты отсутствующего, короткого, неверного и правильного токена |
| PostgreSQL и Redis опубликованы на интерфейсах хоста | Порты хранилищ удалены; пароль и DSN обязательны; API привязан к loopback | Проверка Compose и тест отсутствия учётных данных по умолчанию |
| Строки подключения с паролями попадали в журнал | Логирование полных DSN удалено; ошибки Redis не возвращают исходный URL | Тест неверного URL с контрольным секретом |
| Неограниченный список групп вызывал запросы к БД | Незавершённый matchmaking отключён; тело HTTP-запроса ограничено 64 КиБ | Тест недоступности маршрута до БД |

Исходные оценки скана: четыре medium, одна low. Эксплуатация работающего сервера не проводилась; действующий backend в релиз v4 не включён. Подробные исходные формулировки сохранены в `docs/evidence/security-scan-summary.json`.

## Защита активного приложения

- React выводит имена, заметки и данные источника как текст. Нет исполнения импортированного HTML или JavaScript.
- Обновления принимаются только после проверки схемы каталога, полей всех занятий, группы, дат и SHA-256 содержимого расписания. Пути ограничены каталогом групп; данные имеют ограничения размера и времени загрузки.
- Официальные ссылки допускают только HTTPS на доменах университета без паролей и нестандартных портов.
- Service worker сохраняет конечный список файлов одной сборки. API, JSON расписаний, внешние запросы и запросы с Authorization не попадают в CacheStorage.
- Заметки и задачи хранятся на устройстве. Они не зашифрованы отдельным ключом приложения; доступ определяется защитой устройства и браузерного профиля.
- Android запрещает cleartext-трафик и системное резервное копирование. Ключ релиза находится вне репозитория; пароль защищён Windows DPAPI.
- Публикация проверяет чистый Git, совпадение сборки с HEAD и удалённым main, commit тега, цель черновика и SHA-256 каждого загруженного файла. Отсутствующая контрольная сумма останавливает публикацию.

## Что фактически проверено

`npm test`: 20 тестов прошли, включая все 805 снимков групп, парсер дат/семестров, недоверенные поля, восстановление личной копии, service worker и привязку релиза к commit. `npm run typecheck`: успешно.

Go: тесты `./internal/delivery/http`, `./internal/config`, `./internal/repository/redis` прошли. Эти проверки не доказывают готовность всего устаревшего backend к эксплуатации.

Не завершены: динамическая проверка подписанного APK на устройстве, финальная проверка публикации, полное покрытие оставшегося неиспользуемого кода и зависимостей, нагрузочное тестирование. Университетская авторизация, Wallet/NFC и системные расширения не подключены.
